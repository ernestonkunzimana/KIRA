## 🚀 Quick Start

### Installation (5 minutes)
```bash
cd kigali_watchman/frontend
python -m venv venv
source venv/bin/activate  # Mac/Linux
pip install -r requirements.txt
cp .env.template .env
```

### Run
```bash
# Option 1: Automatic startup
./start.sh              # Mac/Linux
start.bat               # Windows

# Option 2: Manual Streamlit
streamlit run app.py
```

**Opens**: http://localhost:8501

### Default Login
```
Client ID: dashboard
Password: kira-dashboard-2024
```

Or create a new account via **"Create New Account"** link.

## 📞 Support

### Common Issues

| Problem | Solution |
|---------|----------|
| Backend unreachable | Check `KIRA_API_URL` in `.env` |
| Login fails | Verify client_id (case-sensitive) |
| Slow UI | Check backend performance |
| Port conflict | Change `STREAMLIT_SERVER_PORT` in `.env` |

### Debug Mode
```bash
# Enable debug in .env
DEBUG=true

# Check backend logs
tail -f backend/logs/kira.log

# View Streamlit output
streamlit run app.py --logger.level=debug
```

## 🚀 Deployment Commands

### Local Testing
```bash
./start.sh  # or start.bat on Windows
```

### Production (with gunicorn)
```bash
# Backend
gunicorn -w 4 -b 0.0.0.0:5000 backend.main:app

# Frontend
streamlit run app.py \
  --server.port 8501 \
  --server.address 0.0.0.0 \
  --logger.level error
```

### Docker (optional)
```bash
docker build -t kira-frontend -f frontend/Dockerfile .
docker run -p 8501:8501 kira-frontend
```
